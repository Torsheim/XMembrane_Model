# Claim boundary

The current model supports physics-based numerical feasibility, inverse-design and sensitivity studies.

The current model does not establish that:

- the selected independent material-property vector exists experimentally;
- the required receiver resource is practically available;
- the complete membrane module has been mechanically validated;
- electrode and current-collector architecture has been validated;
- long-duration material stability is known;
- system economics have been experimentally demonstrated.

Results should therefore be described as model predictions, inverse-design targets, conditional energy results, or engineering screening values unless experimental validation is explicitly available.
